## application.plist.in / voxedit.plist.in

These files are generated by the formatprinter tool (`--plist`) - see the Makefile in the project root dir.

They declare `CFBundleDocumentTypes`, `LSItemContentTypes` and `UTExportedTypeDeclarations` for every loadable voxel format (`com.github.vengi.*` UTIs).

## thumbnailer.plist.in

Generated by formatprinter (`--qlthumbnail`). Info.plist template for the macOS Quick Look Thumbnail app extension (`com.apple.quicklook.thumbnail`) with `QLSupportedContentTypes` matching the exported UTIs above.
