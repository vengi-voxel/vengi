## application.plist.in / voxedit.plist.in

These files are generated by the formatprinter tool (`--plist`) - see the Makefile in the project root dir.

They declare `CFBundleDocumentTypes`, `LSItemContentTypes` and `UTExportedTypeDeclarations` for every loadable voxel format (`com.github.vengi.*` UTIs).

## entitlements.plist

Generated by formatprinter (`--entitlements`). Host application entitlements for codesign and `CPACK_BUNDLE_APPLE_ENTITLEMENTS` (issue #356):

* `com.apple.security.network.client` / `network.server` (downloads, MCP/server)
* `com.apple.security.files.user-selected.read-write` (open/save dialogs)
* `com.apple.security.files.downloads.read-write`

Wired into Xcode `CODE_SIGN_ENTITLEMENTS`, non-Xcode `codesign --entitlements`, and CPack Bundle.

## voxelthumb.plist.in

Generated by formatprinter (`--qlthumbnail`). Info.plist template for the macOS Quick Look Thumbnail app extension (`com.apple.quicklook.thumbnail`) with `QLSupportedContentTypes` matching the exported UTIs above.

Named `voxelthumb.plist.in` (not `thumbnailer.plist.in`) so the CLI `thumbnailer` target keeps using `application.plist.in`.

## thumbnailer.entitlements

Sandbox entitlements for the Quick Look Thumbnail `.appex` (`com.apple.security.app-sandbox`).

## Packaging layout

CPack DragNDrop produces one combined DMG. Finder thumbnails are not a separate DMG product; they are installed into the editor bundle:

```text
vengi-voxedit.app/Contents/
  MacOS/vengi-voxedit
  MacOS/vengi-thumbnailer
  PlugIns/vengi-voxelthumb.appex/
```

`cmake/apple-install-voxedit-thumbnailer.cmake` performs that embed (+ codesign) for the `voxedit` install component. A matching POST_BUILD step also embeds into the build-tree app for local runs. The standalone CLI `vengi-thumbnailer` / `.app` remains its own install component for command-line use.
